## Product Catalogue Service
 ### Overview

 The Product Catalogue Service is a RESTful microservice built using Spring Boot that manages product-related operations within the system.

## It provides APIs for:

Adding products
Fetching product details
Searching products
Paginated product retrieval
Product management operations

This service is designed following microservices architecture principles and can be integrated with other services like Order Service, Inventory Service, or User Service.


## Features
  ```
  Add new products
  Retrieve product by ID
  Retrieve all products
  Search products by keyword/name/category
  Pagination and sorting support
  DTO-based request/response handling
  Global exception handling
  Request validation
  RESTful API design

```
